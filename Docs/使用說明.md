# 水產養殖監控系統 — 前端使用說明

> 適用版本：React/FastAPI 監控介面（取代原 Streamlit 介面）  
> 目標瀏覽器：**Chrome** 或 **Edge**（主要驗證目標）  
> 安全邊界：**僅限本地可信任網路**，請勿對外公開

---

## 一、系統需求

| 元件 | 需求 |
|------|------|
| Python | 3.12 以上 |
| Node.js / npm | 18 以上（建置前端用） |
| MediaMTX | 已啟動並接受攝影機串流 |
| 瀏覽器 | Chrome 或 Edge（支援 WebRTC） |
| 攝影機來源 | 推流至 `rtsp://<relay-ip>:8554/drone_live` |

---

## 二、啟動步驟

### 步驟 1　啟動 MediaMTX 串流中繼

**桌機 / 筆電（Windows、macOS、Linux）**

```bash
docker compose -f compose.mediamtx.desktop.yml up
```

**Raspberry Pi**

```bash
docker compose -f compose.mediamtx.rpi.yml up
```

啟動後 MediaMTX 會在以下位置接受推流：

```
rtsp://<本機 LAN IP>:8554/drone_live
```

---

### 步驟 2　建置前端（首次或程式碼異動後才需要執行）

```bash
cd src/web/frontend
npm install       # 安裝相依套件（首次）
npm run build     # 編譯並輸出到 src/web/frontend/dist/
cd ../../..
```

> **開發模式** 不需要 build，詳見第六節。

---

### 步驟 3　啟動後端 FastAPI 服務

從專案根目錄執行：

```bash
uvicorn web.app:app --host 0.0.0.0 --port 8000
```

成功啟動後會看到：

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

---

### 步驟 4　開啟前端監控畫面

在 **同一台主機** 上打開瀏覽器，輸入：

```
http://localhost:8000
```

若要從 **同一區域網路的其他裝置** 連線（例如平板），請使用主機的 LAN IP：

```
http://192.168.x.x:8000
```

> ⚠️ 請勿將此位址對外公開，本系統無驗證機制。

---

## 三、前端畫面說明

```
┌─────────────────────────────────────────────────────────┐
│  Aquaculture Monitoring          [Start] [Hide Overlays] │  ← 頂部工具列
├───────────────────────────────────────┬─────────────────┤
│                                       │  Stream:  Live  │
│                                       │  Detection: OK  │
│         Live Video (WebRTC)           │  Viewers:  1    │
│                                       ├─────────────────┤
│   [SVG 疊加層：活動區域框]             │  Activity       │
│                                       │  Medium         │
│                                       │  Score: 52/100  │
│                                       │  Conf: 84%      │
└───────────────────────────────────────┴─────────────────┘
```

### 頂部工具列

| 元素 | 說明 |
|------|------|
| **Start** | 開始監控：啟動 WebRTC 影片播放並通知後端加入偵測工作階段 |
| **Stop** | 停止監控：關閉影片播放，後端在所有觀看者離開後 10 秒內停止偵測 |
| **Hide Overlays / Show Overlays** | 切換是否在影像上顯示活動區域框（不影響後端偵測） |

### 影像區域

- 使用瀏覽器原生 `<video>` 元素直接向 MediaMTX 播放 WebRTC 串流
- 後端 FastAPI **不轉發影像**，延遲最低
- 目標：首幀畫面出現時間 ≤ 3 秒

### 疊加層（Overlay）

- 藍色框：目前偵測到的活動區域，座標已正規化（0.0–1.0），自動對齊影像
- 超過 **500 ms** 未收到新偵測資料時框會自動消失（不影響影片播放）
- 偵測延遲或不可用時影片仍繼續播放

### 右側狀態面板

#### 串流狀態（Stream）

| 狀態 | 說明 |
|------|------|
| `Waiting` | 尚未按下 Start |
| `Connecting…` | 正在連線 MediaMTX |
| `Live` | 正常播放中 |
| `Reconnecting…` | 連線中斷，自動重連中 |
| `Stream Unavailable` | MediaMTX 無法連線 |
| `Degraded` | 畫面品質下降 |

#### 偵測狀態（Detection）

| 狀態 | 說明 |
|------|------|
| `OK` | 偵測正常運作 |
| `Delayed` | 偵測結果延遲，影片仍播放 |
| `Degraded` | 偵測效能下降 |
| `Unavailable` | 偵測暫時無法使用 |

#### 活動面板（Activity）

| 欄位 | 說明 |
|------|------|
| 活動等級 | `Low` / `Medium` / `High` |
| Score | 0–100 活動強度 |
| Confidence | 偵測信心值（百分比） |

## 四、操作流程（標準操作）

```
1. 確認 MediaMTX 已啟動並有攝影機推流
2. 開啟瀏覽器至 http://localhost:8000
3. 按下 [Start]
4. 等待串流狀態變為 Live（≤ 3 秒）
5. 觀察疊加層與活動面板
6. 需要時按 [Hide Overlays] 暫時隱藏框
7. 結束時按 [Stop]
```

> 多個瀏覽器視窗可同時開啟同一個畫面，後端只會執行**一個**偵測迴圈。

## 五、常見問題

### 畫面空白，串流狀態一直是 `Connecting…`

- 確認 MediaMTX 已啟動：`docker compose ps`
- 確認有攝影機推流至 `rtsp://<主機>:8554/drone_live`
- 確認後端服務正在執行（uvicorn）
- 若從其他電腦、平板或手機開啟，請使用後端主機的 LAN IP，例如 `http://192.168.x.x:8000`，避免瀏覽器把 `localhost` 解讀成用戶端自己

### 瀏覽器顯示「WebRTC is not supported」

- 請改用 **Chrome** 或 **Edge**
- 確認是透過 `http://localhost` 或 LAN IP 存取（非 `file://`）

### 疊加層框一閃即逝

- 屬正常行為：超過 500 ms 無新偵測資料框就會消失
- 若偵測狀態顯示 `Delayed`，表示 CPU 負載過高，偵測器跳幀

### 串流狀態變成 `Reconnecting…`

- 後端或 MediaMTX 暫時中斷，瀏覽器會自動重連，不需要重新整理

### 按 Stop 後後端仍在執行

- 屬正常行為：後端等所有觀看者都離開後，會在 **10 秒內** 自動停止偵測

### `/config` 或 `/status` API 回傳錯誤

- 確認後端服務已啟動（埠 8000）
- 確認前端是由 FastAPI 提供（已執行 `npm run build`）

## 六、前端開發模式（不需要 build）

開發時可使用 Vite 開發伺服器，API 請求會自動代理到後端：

```bash
# 先啟動後端
uvicorn web.app:app --host 0.0.0.0 --port 8000

# 再啟動 Vite 開發伺服器
cd src/web/frontend
npm run dev
```

開啟瀏覽器至：

```
http://localhost:5173
```

- 修改 `src/web/frontend/src/` 下的任何檔案後，畫面會即時熱重載
- 所有 `/config`、`/session`、`/status`、`/ws` 請求會自動轉發到 `localhost:8000`

## 七、設定調整

如需調整連線參數，請修改 `src/config/setting.py`：

| 設定 | 預設值 | 說明 |
|------|--------|------|
| `STREAM_URL` | `rtsp://127.0.0.1:8554/drone_live` | 後端偵測讀取的 RTSP 串流網址 |
| `MEDIAMTX_HOST` | `127.0.0.1` | MediaMTX WebRTC 主機位址；預設 loopback 會在 `/config` 自動轉成瀏覽器連入的主機位址 |
| `MEDIAMTX_WEBRTC_PORT` | `8889` | MediaMTX WebRTC 埠號 |
| `SOURCE_ID` | `drone_live` | 串流識別名稱 |
| `STALE_OVERLAY_MS` | `500` | 疊加層消失的閾值（毫秒） |
| `VIEWER_HEARTBEAT_TIMEOUT_SECONDS` | `30` | 觀看者心跳逾時秒數 |
| `IDLE_SHUTDOWN_DELAY_SECONDS` | `10` | 無觀看者後停止偵測的延遲秒數 |
| `BACKEND_PORT` | `8000` | FastAPI 後端埠號 |

修改後重新啟動 uvicorn 即可套用。

## 八、API 快速參考（進階）

| 方法 | 路徑 | 說明 |
|------|------|------|
| `GET` | `/config` | 取得 WebRTC URL 與 WebSocket URL |
| `POST` | `/session/start` | 加入監控工作階段 |
| `POST` | `/session/stop` | 離開監控工作階段 |
| `GET` | `/status` | 取得串流與偵測狀態 |
| `WS` | `/ws/overlays` | 接收即時疊加層資料 |

WebSocket 訊息格式詳見 `specs/001-react-webrtc-face-detection/contracts/websocket-overlay.md`。
