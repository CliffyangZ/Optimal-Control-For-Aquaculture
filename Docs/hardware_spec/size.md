### 安裝注意事項 (Notes for Assembly)
1. **排線相容性**：Raspberry Pi Zero 2 W 需使用 **Mini CSI 轉接排線** (1.0mm 轉 0.5mm pitch)，與 Pi 5 內附的排線規格不同。
2. **濾鏡適配**：52mm 偏光鏡尺寸大於鏡頭模組，建議設計 3D 列印轉接環或使用 37-52mm 轉接圈固定。
3. **散熱需求**：Zero 2 W 在執行長時間 RTSP 推流時會發熱，建議安裝於機架散熱良好的通風位。
4. **電源配置**：建議由無人機電源模組提供穩定的 **5V/2.5A** 給 Raspberry Pi，避免因電壓不穩導致影像中斷。
