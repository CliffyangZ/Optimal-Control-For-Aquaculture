## 参数详解

### 1. HSV 色彩空间变换

**HSV 是什么？**
```
RGB (红绿蓝)         HSV (色调-饱和度-亮度)
└─ 计算机存储         └─ 人眼感知
  R: 255             H: 色调 (0-360°, 颜色)
  G: 128             S: 饱和度 (0-100%, 纯度)
  B: 64              V: 亮度 (0-100%, 明暗)
```

#### hsv_h = 0.015（色调变化）

**含义**：改变图像的颜色

```
原始图像                    增强后的变体
┌──────────────┐           ┌──────────────┐
│ 蓝绿色 (水)   │  h=0.015  │ 绿色/青色     │
│ 金色 (饲料)   │   ─────→  │ 黄色/橙色     │
│ 黑色 (鱼体)   │           │ 紫色/棕色     │
└──────────────┘           └──────────────┘

范围 = [-0.015, +0.015]
     = ±5.4° (在360°圆形色环上)
```

**为什么需要？**
```
水下环境的颜色变化很大：
├─ 不同时段的光照
├─ 不同水质（浑浊度）
├─ 不同相机白平衡
└─ 季节和天气变化

hsv_h 让模型学会识别不同颜色的鱼和饲料
```

**调优建议**：
```
hsv_h = 0.015 ✅ 当前值（水下环境合适）

其他情况：
├─ 水下环境颜色稳定：hsv_h = 0.01 (减弱)
├─ 颜色变化大：hsv_h = 0.03 (加强)
└─ 不确定：保持 0.015
```

#### hsv_s = 0.7（饱和度变化）

**含义**：改变颜色的纯度（从彩色到灰度）

```
s = 0.7              0%              100%
(当前值)
饱和度变化   完全灰化          原始彩色
范围      [-0.7, +0.7]    [-1, 1]

图像变化：
原始           减弱饱和度          增强饱和度
┌────────┐    ┌────────┐          ┌────────┐
│彩色鱼  │    │淡色鱼  │          │鲜艳鱼  │
│金饲料  │ →  │灰棕饲料│   或 →   │亮金饲料│
└────────┘    └────────┘          └────────┘
```

**为什么需要？**
```
s = 0.7 的影响：
└─ 50%的概率：饱和度 = 原始 - 0.7 (更灰)
└─ 50%的概率：饱和度 = 原始 + 0.7 (更鲜艳)

好处：
├─ 模型对光照条件鲁棒
├─ 学会在不同对比度下识别
└─ 水下照明变化很大时特别有用
```

**调优建议**：
```
hsv_s = 0.7 ✅ 当前值（推荐，水下环境需要）

其他情况：
├─ 保守值：hsv_s = 0.3 (较小变化)
├─ 激进值：hsv_s = 0.9 (大幅变化)
└─ 当前值最适合水下场景
```

#### hsv_v = 0.4（亮度变化）

**含义**：改变图像的明暗程度

```
原始图像       hsv_v = 0.4 的变化
┌──────────┐   ┌──────────┐  ┌──────────┐
│较亮鱼    │   │暗鱼      │  │非常亮鱼  │
│清晰背景  │ → │模糊背景  │或│高曝光    │
└──────────┘   └──────────┘  └──────────┘

范围 = [-0.4, +0.4]
     = 亮度在40%范围内波动
```

**为什么需要？**

```
水下拍摄的光照变化原因：
├─ 日出/日落的不同阳光角度
├─ 阴天/晴天的光照差异
├─ 不同深度的光衰减
├─ 灯光波动
└─ 水的浑浊度变化

V = 0.4 让模型适应各种光照条件
```

**调优建议**：
```
hsv_v = 0.4 ✅ 当前值（推荐）

其他情况：
├─ 如果拍摄环境光照稳定：hsv_v = 0.2
├─ 如果光照变化极大：hsv_v = 0.6
└─ 不建议超过0.7（会破坏过度）
```

### 2. 几何变换

#### degrees = 10（旋转）

**含义**：旋转图像 ±10度

```
原始图像              旋转变体
┌────────┐   ┐  ┌────────┐
│ Fish   │ 向├──→∘ Fish
│        │   └→ (旋转角度)
└────────┘
```

**实际效果**：
```
degrees = 10 时的概率分布：

   0°   ±3°  ±5°  ±7° ±10°
   │    ││   ││   ││  ││
   ▓    ▒░   ▒░   ▒░ ▒░
━━━┼━━━━┼━━━┼━━━┼━━┼━━━━━ 旋转角度
  -10  -7  -5  -3   0  +3  +5  +7  +10

每次数据增强随机选择一个角度
```

**为什么需要？**

```
为什么鱼会有不同角度？
├─ 鱼在水中自由游动
├─ 饵料随水流运动
├─ 相机可能不完全水平
└─ 检查/检修时相机角度变化

现实中的角度变化：
0° (正面)  ↔  45° (斜向)  ↔  90° (侧面)  ↔  135°

degrees=10 让模型看到：
-10° ← 原始0° → +10°
```

**调优建议**：
```
degrees = 10 ✅ 当前值（合理）

其他情况：
├─ 相机固定不动：degrees = 3 (减弱)
├─ 鱼活动多，角度多变：degrees = 20 (加强)
└─ 不建议超过30°（会过度扭曲）
```

**对mAP的影响**：
```
degrees增加 → 模型对旋转更鲁棒 → mAP+0.5-1%
但：完全不旋转 → 模型只能识别特定方向的鱼
```

---

#### translate = 0.1（平移）

**含义**：将图像向上/下/左/右移动 ±10%

```
原始位置         平移后
┌─────────┐    ┌─────────┐
│         │    │  Fish   │
│ Fish    │ →  │ (向右10%│
│         │    │         │
└─────────┘    └─────────┘

translate = 0.1
= 图像宽度/高度的 ±10% 位移
```

**实际数值**：
```
假设图像 640×640 像素

translate = 0.1 意味着：
├─ 水平移动：±64像素 (0.1 × 640)
├─ 竖直移动：±64像素 (0.1 × 640)
└─ 目标可能从中心移到边角

这样的平移会产生什么？
1. 目标移出边界（被裁剪）
2. 空白区域填充（背景）
```

**为什么需要？**

```
实际场景中的位置变化：
├─ 鱼不一定在画面中心
├─ 饲料可能掉到边角
├─ 相机固定时，目标仍在移动
└─ 不同帧中，目标位置不同

translate让模型学会：
"无论在哪个位置，都能识别Fish和Feed"
```

**调优建议**：
```
translate = 0.1 ✅ 当前值（合理）

其他情况：
├─ 目标总在中心：translate = 0.05 (减弱)
├─ 位置变化大：translate = 0.2 (加强)
└─ 不建议超过0.3（会大量损失目标）
```

---

#### scale = 0.5（缩放）

**含义**：缩放图像大小 0.5x 到 1.5x

```
缩放变体：
0.5x              1.0x (原始)        1.5x
┌───┐             ┌─────────┐        ┌──────────────┐
│   │Fish         │ Fish    │        │   Fish       │
│   │(小)      →  │(正常)   │  或  →│   (大)       │
└───┘             └─────────┘        └──────────────┘
```

**scale = 0.5 的含义**：
```
范围 = [0.5, 1.5]

实际操作：
├─ 50%概率：缩放到 0.5-1.0 倍 (缩小，变小目标)
├─ 50%概率：缩放到 1.0-1.5 倍 (放大，变大目标)
└─ 缩放后重新调整到640×640（保持输入大小）
```

**为什么需要？**

```
为什么Fish大小会变化？
├─ 近距离的鱼看起来很大
├─ 远距离的鱼看起来很小
├─ 不同种类的鱼大小不同
├─ 幼鱼 vs 成鱼
└─ 相机焦距变化

scale让模型学会识别：
小Fish (相当于0.5x的Fish)
中Fish (1.0x，标准大小)
大Fish (1.5x，大个体)
```

**对小目标检测的影响**：

```
你的任务：检测"鱼"和"饲料"（都是相对小的目标）

scale = 0.5 的好处：
├─ 生成更小的Fish变体（训练时需要识别小目标）
├─ 这对"检测小饲料"特别重要
└─ mAP可能 +1-2%

缺点：
├─ 训练时间增加（需要处理多个尺度）
└─ 可能丢失细节
```

**调优建议**：
```
scale = 0.5 ✅ 当前值（强烈推荐，对小目标很帮助）

其他情况：
├─ 目标大小变化小：scale = 0.3 (减弱)
├─ 目标大小变化大：scale = 0.7 (加强)
└─ 对于小目标检测，不要低于0.3
```

### 3. 翻转增强

#### flipud = 0.5（上下翻转）

**含义**：50%概率上下翻转图像

```
原始图像              上下翻转后
┌──────────┐         ┌──────────┐
│          │         │ Fish     │
│  Fish    │  50%    │ (倒过来)│
│          │  ──→    │          │
└──────────┘         └──────────┘
```

**为什么需要？**

```
Fish 什么时候会上下颠倒？
├─ 鱼在水中翻身
├─ 从不同角度观看
├─ 相机安装角度不同
├─ 鱼跃出水面又回到水里

但是：水下Fish的正面几乎不会颠倒！
```

**调优建议**：
```
flipud = 0.5 ⚠️ 当前值（需要考虑）

更好的选择：
├─ flipud = 0.2-0.3 （降低，因为鱼不常上下颠倒）
│  原因：真实场景中鱼不会倒过来
│
└─ flipud = 0.0 （关闭）
   原因：鱼的背和肚不同，上下翻转破坏了这个特征

建议改为：flipud = 0.1 （保留一点，以防万一）
```

---

#### fliplr = 0.5（左右翻转）

**含义**：50%概率左右翻转图像

```
原始图像              左右翻转后
┌──────────┐         ┌──────────┐
│          │         │      ◀─ │
│ Fish ─→  │  50%    │   Fish  │
│          │  ──→    │          │
└──────────┘         └──────────┘
```

**为什么需要？**

```
Fish 左右方向的自然性：
├─ 鱼可以向左游动
├─ 也可以向右游动
├─ 大多数鱼是对称的（左右）
├─ 从各方向的鱼样本都能学到特征
└─ 真实环境中，鱼的朝向完全随机

fliplr = 0.5 很合理！✅
不但保持现实性，还加强了对称性学习
```

**调优建议**：
```
fliplr = 0.5 ✅ 当前值（非常推荐）

其他情况：
├─ 如果鱼类有明显的左右不对称特征
│  （比如眼睛只在一侧）
│  → 降低到 fliplr = 0.0 (关闭)
│
└─ 否则保持 0.5
```

## 增强参数的组合效果

### 为什么要用多个增强参数？

```
单个增强参数的局限：
├─ 只旋转：模型见不到颜色变化的Fish
├─ 只改HSV：模型见不到不同大小的Fish
├─ 只平移：模型见不到不同角度的Fish
└─ 只翻转：模型见不到有角度的Fish

多个增强的组合：
Fish1 (原始)     →  Fish1' (旋转+HSV变化)
Fish2 (平移)     →  Fish2' (缩放+翻转)
Fish3 (颜色淡)   →  Fish3' (旋转+平移+颜色)

结果：模型见过几百种Fish的变体
     → 识别能力大幅提升 ✅
```

### 每个Batch中发生什么？

```
Batch 中的 16 张图像：

图像1: 原始 + HSV + 旋转5° + 平移+缩放小 + 翻转
图像2: 原始 + HSV + 旋转-7° + 平移 + 缩放大 + 不翻转
图像3: 原始 + HSV + 不旋转 + 不平移 + 缩放中 + 翻转
...
图像16: 原始 + 无增强

每张图都有不同的增强组合！
→ 数据多样性非常高
→ 模型学到更鲁棒的特征
```

## 调优检查清单

### 监控训练时是否有效

```
在 WandB 中观察：

1. 训练loss是否平稳下降？
   ✅ 是 → 数据增强合适
   ❌ 否 → 增强过度，降低参数

2. 验证mAP是否在上升？
   ✅ 是 → 增强有效
   ❌ 否 → 尝试不同的增强组合

3. 增强后是否看不清图像？
   ✅ 增强数据可视化 (在trainer中检查)
   └─ 如果图像无法识别 → 增强过度

4. 过拟合是否减少？
   └─ Training mAP vs Validation mAP 的差距
   ✅ 差距缩小 → 增强有效防止过拟合
```
