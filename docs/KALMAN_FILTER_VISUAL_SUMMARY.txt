┃ STATE VECTOR (狀態)                                                        ┃
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫
┃                                                                            ┃
┃            x = [ μ   ]     where  μ = log(飼料面積) [log pixels²]        ┃
┃                [ μ̇   ]            μ̇ = 消耗速率 [%/frame]             ┃
┃                                                                            ┃
┃  Example: μ = 6.0, μ̇ = -0.02                                            ┃
┃  →  飼料面積 ≈ 403 px², 每幀減少 2%                                      ┃
┃                                                                            ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ STATE TRANSITION MATRIX                                                   ┃
┣━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┫
┃                                                                            ┃
┃              ┌─────┐                                                       ┃
┃        F =   │ 1  Δt│      (假設消耗速率恆定)                             ┃
┃              │ 0   1 │                                                     ┃
┃              └─────┘                                                       ┃
┃              Δt = 1 frame                                                 ┃
┃                                                                            ┃
┃  x_{t+1} = F · x_t                                                        ┃
┃  下一幀 = F × 當前幀                                                      ┃
┃                                                                            ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛


════════════════════════════════════════════════════════════════════════════════
                         🔄 ALGORITHM: 5 STEPS PER FRAME
════════════════════════════════════════════════════════════════════════════════

NEW FRAME t with measurement z_t:
   ↓
   ├─→ 【Step 1】PREDICT STATE
   │      x̂⁻_t = F · x̂_{t-1}
   │      P⁻_t = F · P_{t-1} · F^T + Q
   │      └─→ 預測當前面積 & 速率
   │
   ├─→ 【Step 2】INNOVATE (測量驚訝度)
   │      y_t = log(z_t)
   │      γ = y_t - x̂⁻_t[0]     (差異有多大？)
   │      S = P⁻_t[0,0] + σ_R²    (總不確定度)
   │      └─→ 計算測量與預測的偏差
   │
   ├─→ 【Step 3】KALMAN GAIN (信任度)
   │      K = P⁻_t[0,0] / S
   │      K ∈ [0, 1]
   │      K = 1  →  完全信任測量
   │      K = 0  →  完全信任預測
   │      └─→ 決定相信多少
   │
   ├─→ 【Step 4】UPDATE STATE
   │      x̂_t = x̂⁻_t + K · γ
   │      P_t = (1 - K) · P⁻_t
   │      └─→ 融合預測與測量
   │
   └─→ 【Step 5】OUTPUT (轉換回像素空間)
          Â_t = exp(x̂_t[0] + P_t[0,0]/2)    ← 無偏估計
          Rate_t = x̂_t[1] × 100  (%/frame)
          CI = [exp(x̂[0] - √P[0,0]), exp(x̂[0] + √P[0,0])]


════════════════════════════════════════════════════════════════════════════════
                    🎯 CORE EQUATIONS (for poster)
════════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────┐
│                   PREDICT EQUATIONS                          │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   x̂⁻ = F · x̂          Prior state estimate               │
│   P⁻ = F·P·F^T + Q     Prior covariance                    │
│                                                              │
│   F = [1  1]  (one-step transition)                        │
│       [0  1]                                                │
│                                                              │
│   Q = σ_Q·[1/4  1/2]   Process noise                       │
│           [1/2   1  ]   (controls rate variability)        │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                   UPDATE EQUATIONS                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   γ = y - h·x̂⁻        Innovation (measurement surprise)  │
│   S = h·P⁻·h^T + R     Innovation covariance               │
│   K = (P⁻·h^T) / S     Kalman gain (0 ≤ K ≤ 1)            │
│   x̂ = x̂⁻ + K·γ       Posterior state                      │
│   P = (I - K·h)·P⁻     Posterior covariance                │
│                                                              │
│   h = [1, 0]  (observation matrix)                         │
│   R = σ_R²    (measurement noise variance)                 │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│                   OUTPUT EQUATIONS                           │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   Unbiased Area Estimate:                                  │
│   Â = exp(μ̂ + σ²_μ/2)   ← Important! Don't forget /2    │
│                                                              │
│   Consumption Rate:                                         │
│   Rate [%/frame] = μ̇ × 100                                │
│   Rate [%/sec]   = μ̇ × 100 × fps                         │
│                                                              │
│   Confidence Interval (1-sigma):                           │
│   Lower = exp(μ̂ - σ_μ)                                    │
│   Upper = exp(μ̂ + σ_μ)                                    │
│   where σ_μ = √(P[0,0])                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘

┃                                                                           ┃

                        📊 EXAMPLE WALKTHROUGH
════════════════════════════════════════════════════════════════════════════════

Given:
  σ_R = 0.15  (±15% detector error)
  σ_Q = 0.001 (smooth rate estimation)

Frame 0: Raw measurement z₀ = 500 px²
  ├─ y₀ = log(500) = 6.215
  ├─ Initialize: x̂ = [6.215, 0]ᵀ
  ├─ Estimate: Â = exp(6.215 + 0.15²/2) ≈ 505 px²
  └─ Rate = 0 %/frame (just started)

Frame 1: Raw measurement z₁ = 480 px²
  ├─ PREDICT:
  │   x̂⁻ = F·x̂ = [6.215, 0]ᵀ
  │   P⁻ = ... ≈ [[0.024, 0], [0, 0.001]]
  │
  ├─ INNOVATE:
  │   y = log(480) = 6.175
  │   γ = 6.175 - 6.215 = -0.040
  │   S = 0.024 + 0.0225 = 0.047
  │
  ├─ GAIN:
  │   K = 0.024 / 0.047 ≈ 0.51  (moderate trust)
  │
  ├─ UPDATE:
  │   x̂ = [6.215, 0] + 0.51·[-0.040, ?]ᵀ
  │   x̂ ≈ [6.195, -0.010]ᵀ
  │
  └─ OUTPUT:
     Â ≈ 492 px² (decreased)
     Rate = -0.010 × 100 = -1.0 %/frame
     Confidence: [470, 517] px² (1-sigma)


════════════════════════════════════════════════════════════════════════════════
                          ✅ WHY THIS WORKS
════════════════════════════════════════════════════════════════════════════════

✓ NOISE MODEL
  └─ 檢測噪聲確實是乘法性的 → log transform 使其為加法性
  └─ Kalman Filter 對加法高斯噪聲是最優的

✓ JOINT ESTIMATION
  └─ 同時估計面積和消耗速率（不是事後計算微分）
  └─ 消耗速率更光滑，更有用於決策

✓ UNBIASED ESTIMATES
  └─ exp(μ + σ²/2) 校正對數正態分佈偏差
  └─ 避免系統低估飼料面積

✓ UNCERTAINTY QUANTIFICATION
  └─ 從協方差矩陣自動計算置信區間
  └─ 知道每個估計的可信度

✓ ADAPTIVE FILTERING
  └─ Kalman Gain 自動在測量和預測間權衡
  └─ 高噪聲時更信任預測，低噪聲時更信任測量
